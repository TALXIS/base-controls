import { Meta, Title, Subtitle, Heading, Source } from '@storybook/blocks';

<Meta title="PCF Context/Overview" />

<Title>PCF Context Provider</Title>
<Subtitle>Provide a real or synthesized PCF context to any descendant component tree.</Subtitle>

<div className="form-docs-copy">
  <p>
    <code>PcfContextProvider</code> is a small utility provider that supplies a PCF-compatible context to anything rendered beneath it.
  </p>
  <p>
    Any component that expects a PCF context can consume this provider directly, whether it is used in a grid, a nested control, or any other standalone React surface that needs PCF-compatible behavior.
  </p>
  <p>
    The key relationship is simple: render a component inside <code>PcfContextProvider</code>, and that component can then read the current PCF context through the <code>usePcfContext</code> hook.
  </p>
</div>

<Heading>What it does</Heading>

<div className="form-docs-copy">
  <p>
    The provider accepts an optional base <code>context</code>. When one is supplied, the provider reuses it as the base for descendants.
  </p>
  <p>
    When a real PCF context is not available, it creates a compatible sample context through the local <code>PcfContextFactory</code>. That makes it useful in browser-only demos and local development surfaces where components still need access to a PCF-shaped environment.
  </p>
  <p>
    Optional <code>userSettings</code> let you seed locale-sensitive parts of the generated context when no Xrm-backed context exists.
  </p>
</div>

<Heading>Why it exists as a standalone utility</Heading>

<div className="form-docs-copy">
  <p>
    <code>PcfContextProvider</code> is infrastructure that makes a PCF context available to any descendant component tree.
  </p>
  <p>
    Its job is simply to bridge components into a PCF-shaped runtime context, either by passing through a real context or by synthesizing one for local rendering and development scenarios.
  </p>
  <p>
    Components do not receive that context through props. Instead, they access it from the provider through <code>usePcfContext</code>, which is the hook-level entry point for anything rendered inside the provider boundary.
  </p>
</div>

<Heading>Typical usage</Heading>

<div className="form-docs-copy">
  <p>
    Wrap the part of the tree that needs access to <code>usePcfContext</code>. A child rendered inside the provider can then read the active PCF context directly from the hook.
  </p>
</div>

<Source
  language="tsx"
  dark
  code={`const ContextConsumer = () => {
  const context = usePcfContext();

  return <div>{context.userSettings.userName}</div>;
};

<PcfContextProvider
  userSettings={{
    lcid: 1033,
    formatInfoCultureName: 'en-US',
  }}
>
  <ContextConsumer />
</PcfContextProvider>`}
/>
