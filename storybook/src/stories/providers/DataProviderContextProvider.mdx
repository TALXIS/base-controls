# DataProviderContextProvider

`DataProviderContextProvider` hands a data provider to every grid and checklist below it. `Grid` and `CheckList` read their provider from it, once, when they mount.

Inside a [**DatasetControl**](?path=/docs/datasetcontrol-get-started-overview--overview), which is the recommended way to show a grid, the control loads the provider and provides it, so you don't add one yourself. Outside one, nothing loads the provider for you: call `refresh()` on it yourself.

## Provide a provider

<Source
  language="tsx"
  dark={false}
  code={`import { createClientSideRowModelModule, DataProviderContextProvider, Grid, PcfContextProvider } from '@talxis/base-controls';

products.refresh();

export const Products = () => (
  <PcfContextProvider>
    <DataProviderContextProvider provider={products}>
      <Grid modules={{ rowModel: createClientSideRowModelModule() }} />
    </DataProviderContextProvider>
  </PcfContextProvider>
);`}
/>

## Read the provider

`useDataProvider()` returns the provider from the nearest `DataProviderContextProvider`, or from a loaded `DatasetControl`. It throws when there is none.

<Source
  language="tsx"
  dark={false}
  code={`import { useDataProvider } from '@talxis/base-controls';

const RecordCount = () => {
  const provider = useDataProvider();
  return <span>{provider.getRecords().length} records</span>;
};`}
/>
